# ZillionSMP — strona serwera

Gotowa, responsywna strona statyczna. Otwórz `index.html` lokalnie lub wrzuć cały folder na hosting obsługujący statyczne pliki (np. własny hosting, GitHub Pages albo Netlify).

## Przed publikacją

- Sprawdź, czy `zillionsmp.pl` jest poprawnym adresem do gry.
- Uzupełnij sekcję FAQ o wspieraną wersję Minecrafta i kanał kontaktu administracji.
- Google Fonts jest używany jako opcjonalne źródło krojów pisma; w razie braku połączenia strona korzysta z fontów systemowych.

Strona nie pokazuje zmyślonego statusu online ani liczby graczy. Przycisk „Kopiuj IP” kopiuje adres serwera do schowka.
